# Xiaomi MiTV-MOSR1 (codename hermano_eu), Android TV 11 (SDK 30), firmware RTT8.210119.001.1129
# MediaTek MT5867. European firmware — no Xiaomi settings app, uses stock android.settings.* intents.
# Stock launcher: com.google.android.tvlauncher (disabled by launcher/build-and-install.sh).
# Live TV app: com.mitv.livetv (owns SelectInputActivity — the HDMI/source switcher).
#
# Apply:   TV_HOST=192.168.1.8 tools/disable.sh examples/xiaomi-mitv-mosr1/debloat.txt
# Undo:    TV_HOST=192.168.1.8 tools/restore.sh examples/xiaomi-mitv-mosr1/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line to keep it.
#
# DO NOT DISABLE on this model (verified with dumpsys):
#   com.mitv.livetv              owns .input.SelectInputActivity – the HDMI/source switcher lives
#                                inside the Live TV app; disabling it kills input switching
#   mitv.service                 PERSISTENT; hosts TvServer, TvSettingService, remote key handling
#   com.mitv.overseaservice      PERSISTENT; hosts .netflixService (Netflix key on the remote)
#   com.mediatek.network         PERSISTENT network monitor
#   com.mediatek.tvinput         HDMI / tuner input framework
#   com.mediatek.tv.service      core TV service
#   com.mi.bluetooth             remote + Bluetooth pairing
#   com.google.android.tv.remote.service   phone-as-remote (user chose to keep)
#   com.google.android.katniss             Google Assistant (user chose to keep)
#   com.google.android.apps.mediashell     Chromecast built-in (user chose to keep)
#   com.xiaomi.mitv.updateservice          OTA updates (user chose to keep)
#   com.mitv.updater                       OTA updater (user chose to keep)
#   com.xiaomi.android.tvsetup.partnercustomizer   safe to leave; removing it can break UI theming
